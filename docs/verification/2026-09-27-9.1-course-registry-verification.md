## Documented residuals (deviations, flagged not silent)

1. **AppIntents `LessonLanguage` display dict stays literal** — empirically
   framework-forced: AppEnum `@Parameter` persists rawValue (switching would
   change stored Shortcut values, forbidden by the behavior-preservation
   rule), and `appintentsmetadataprocessor` rejects computed display
   representations (requires literal strings). Residual per new language: one
   registry row + one enum case + one literal display line, pinned by
   `testAppIntentsLessonLanguageIsRegistryBacked`.
2. **`WidgetSnapshot.placeholder` literals kept** — file compiles into both
   app and widget-extension targets (Foundation-only contract; registry is
   app-target-only). Gallery seed shown only before first app write; not a
   mapping table.
3. **`ListenView.packId(for:)` untouched** — slug→content-pack-id table with
   empty default, no English path, out of the listed scope.
4. **`gen_lesson_catalog.py` / generated catalog untouched** — generation is
   orchestrator-gated; pack content did not change.
